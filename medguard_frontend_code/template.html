How MedGuard reads your list

One list. Every pair. One result.

MedGuard works out which medicines you mean, checks every pair, and separates recorded interactions from combinations the database does not cover.

Major  Highest recorded severity
Moderate  Clinically significant recorded interaction
Minor  Lower recorded severity
Unclassified  Interaction recorded without a severity
Not covered  Not in the database. This is not the same as safe.
Important

Use MedGuard as a screening tool

A database result is not a diagnosis and does not tell you to start, stop or change a medicine. If you are worried about a combination, talk to a pharmacist or doctor.
